How it works

1. The model (or a keyword parser when offline) returns JSON: which tool, which arguments.
2. forecast(store, days) calls POST :8104/forecast; if that service is down it answers from the trained model's metrics.json. metrics() reads the scores.
3. The model is asked again with the result and writes the reply.

POST /ask {"text": "..."} → {response, provider, model, tool_calls}
