# The film

`demo/film.mp4` is 90 seconds in four chapters, made for engineers and project managers who have ninety seconds.

1. **What it does** (0 to 17 s): a terminal prompt runs the project's real first command and the response becomes a printed object. The agent asked the forecast service itself. Then the stake: The course version shipped a key in source. Can an agent run with no key at all?
2. **How it is built** (17 to 40 s): a paper model of the pipeline, stage by stage, with the reveal: Course version → here, the one line of code that matters, the API call and the tests.
3. **The proof** (40 to 68 s): the real app, recorded. Forecast question: the tool call, shown Which model won: read from metrics.json Plain question, no tool; badge says offline
4. **The answer** (68 to 90 s): 0, API keys in source · three providers behind one door. And it ships. One limit: One tool round, no memory. Replies are summaries. Then the prompt types `just setup && just up`.

`demo/film-60s.mp4` is the same without the proof chapter. `demo/demo.mp4` is the plain captioned walkthrough of the app.

Every number in the film comes from the project's own metrics, findings or a live response; nothing is drawn by hand. The film pipeline lives in the author's workspace, not in this repo.
